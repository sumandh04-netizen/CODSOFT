## Objective
Create meaningful visualizations (bar, line, pie, histogram, scatter charts)
using Matplotlib and Seaborn, with proper titles, labels, legends and color
schemes, and combine them into a single dashboard-style output.

## Files in this folder
| File | Description |
|---|---|
| `sales_dataset.csv` | Input dataset (cleaned customer/sales data). |
| `source_code.py` | Main visualization script. |
| `output.png` | Output: 6-panel dashboard image. |
| `requirements.txt` | Python dependencies required to run the script. |

## Charts included in the dashboard
1. **Bar chart** - Average purchase amount by city
2. **Line chart** - Monthly customer signup trend
3. **Pie chart** - Customer gender distribution
4. **Histogram** - Purchase amount distribution
5. **Scatter plot** - Age vs. purchase amount, colored by rating
6. **Bar chart** - Customer rating counts

## How to run
```bash
pip install -r requirements.txt
python source_code.py
```

## Bonus
An interactive version of this dashboard can be built in Power BI or Tableau
by importing `sales_dataset.csv` directly.
