## Objective
Load a dataset, examine it using descriptive statistics, identify trends,
distributions and relationships between variables, detect outliers, and
answer key business questions using summary statistics.

## Files in this folder
| File | Description |
|---|---|
| `sales_dataset.csv` | Input dataset (cleaned customer/sales data carried over from Task 1). |
| `source_code.py` | Main EDA script. |
| `output.png` | Output: 6-panel EDA visualization grid (distributions, outliers, correlations). |
| `findings_report.txt` | Bonus: short written report of key findings. |
| `requirements.txt` | Python dependencies required to run the script. |

## What the script does
1. Loads the dataset and prints `.describe()` summary statistics.
2. Detects outliers in `PurchaseAmount` using the IQR method.
3. Answers business questions such as:
   - Which city has the highest average purchase amount?
   - Is there a correlation between customer age and purchase amount?
   - How is customer satisfaction (rating) distributed?
4. Produces a 6-panel chart (`output.png`) covering age distribution,
   purchase amount distribution, outlier boxplot, average purchase by city,
   age vs. purchase scatter plot, and rating counts.
5. Writes a short findings report (`findings_report.txt`).

## How to run
```bash
pip install -r requirements.txt
python source_code.py
```
